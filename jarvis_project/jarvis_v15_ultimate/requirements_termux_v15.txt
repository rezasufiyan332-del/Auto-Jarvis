# ===============================================================
# TROUBLESHOOTING
# ===============================================================

# Problem: "ImportError: No module named 'xxx'"
# Solution:
#    1. Check if module is in excluded list above
#    2. pip install xxx
#    3. If it fails, it's likely incompatible with Termux
#    4. Look for cloud-based alternative

# Problem: High memory usage
# Solution:
#    1. Reduce concurrent operations
#    2. Clear Python cache: find . -name "*.pyc" -delete
#    3. Restart JARVIS: pkill -f python
#    4. Monitor with: top -n 1 | grep python

# Problem: Termux-API not working
# Solution:
#    1. Install Termux-API app from F-Droid
#    2. Grant all permissions in Android settings
#    3. Run: termux-setup-storage
#    4. Test: termux-api-status

# Problem: Slow performance
# Solution:
#    1. Check background processes
#    2. Reduce AI model usage (switch to faster models)
#    3. Enable caching if disabled
#    4. Close other Android apps
